# Controls and settings

| Button | Play | Menus |
| --- | --- | --- |
| D-pad | Move; Up interacts with Galaxy doors/switches | Navigate; hold to repeat/scroll |
| A | Jump; enter world-map locations | Confirm |
| B | Shoot; throw flower power in Dreams | Back/cancel |
| X | Original DOS status panel | Delete in supported name editors |
| Y | Pogo in Keen 1–6; touched switches/locations in Keen 1–3 | No Dreams pogo |
| Start | Game menu | Open/close where supported |
| Select | Help where available | Help |

Existing Core Input remaps are preserved.

## Independent per-episode HUD

Default **Enhanced**. Keen 1–3 use **On / Enhanced / Off**: their DOS originals had no always-visible HUD, so this is a port addition. Keen 4–6 and Dreams use **Original / Enhanced / Off**. X status remains available in all modes.

| Episode | Basic/original display | Enhanced addition |
| --- | --- | --- |
| Keen 1 | Score, lives, ammo, relevant keys | Ship-part progress on map |
| Keen 2 | Score, lives, ammo, relevant keys | Cities-saved progress on map |
| Keen 3 | Score, lives, ammo, relevant keys | Active ankh timer |
| Keen 4–6 | Native scorebox | Required gem colors and held gems |
| Dreams | Native scorebox | Relevant keys/yellow Boobus Bomb counters |

Irrelevant rows/world-map keys/gems are hidden. Enhanced can look identical to basic when no extras apply. Dreams counters remain behind the status popup.

## Auto Save/manual saves

Default **On** writes verified checkpoints after level completion/map return. **Prompt** asks using a themed dialog. **Off** preserves the previous autosave. Manual saves remain available through Start → Save/Load; occupied slots ask before overwriting. Slot counts follow each engine. Normal level/map saves are supported; death/transitions/cinematics can restrict saving. Autosave is separate from manual slots. Native Pocket Memories are unsupported.

## Core Volume

Default **100%**. Choices: 100%, 75%, 50%, 25%, Mute. IDs, priorities and playback timing are unchanged.

## View Mode

Available above HUD in every episode, with independent saved choices. Default **Enhanced (240 lines)**; **Original (200 lines)** is also available. Gameplay renders extra scenery without rescaling the original pixels. Fixed 200-line menu/intro artwork retains its proportions with matching background filling the 240-line canvas. Original centers the 200-line picture with black margins. The global Pocket aspect stays **5:4**.

Keen 4-6 switches refresh rows/camera bounds at a gameplay frame boundary. Modes can be changed during play without restarting the level. Existing per-episode choices remain saved; defaults apply when no choice has been saved.
